Five checks per signature

Real validation, not a viewer's guess.

PDF readers show a yellow “?” on most Indian government documents because they don't ship the CCA India roots. SignField does, and checks every signature in the file properly.

Integrity

Bytes unchanged

The signed byte range hashes to exactly what the signer signed.

Coverage

Later edits caught

Reports whether the signature covers the whole file, and anything added after signing.

Chain

Up to CCA India

Builds a path to a bundled root: 2011, 2014, 2015 SPL, 2022 and 2022 SPL.

Time

Valid when signed

Judged on the document's own signing date, so an old Aadhaar isn't failed for an expired cert.

Revocation

OCSP or CRL

Asks the certifying authority whether the signer's certificate was revoked.

Private

Files stay local

No upload. The only network traffic is OCSP, CRL and AIA lookups to the CAs.

Verified copy

Swap the “?” for a tick.

For a valid file, SignField builds a flattened copy where the signature box shows a green tick and “Signature valid” instead of “Signature Not Verified”. Handy for portals and people who only look at the box.

The copy is not digitally signed. Its Keywords field holds the original's SHA-256, so anyone can match it back. Keep the original for anything that verifies signatures.

Install

One command. Updates through APT.

For Debian 13 (trixie) on x86_64, including Thallium 81. SignField is tied to Debian 13's Python 3.13 and PyQt6.

curl -fsSL https://signfield.thallium81.dev/install.sh | sh

Or grab the package directly: signfield_@VERSION@_amd64.deb, then sudo apt install ./signfield_@VERSION@_amd64.deb.

Read before you run

What the install script does.

A short POSIX sh file. Here is everything it does, in order.

  1. Checks your system. It stops unless this is Debian 13 on amd64 with APT.
  2. Asks for your password once via sudo or pkexec, because adding an APT source needs root. Don't pipe it into sudo yourself.
  3. Downloads the signing key and checks it against a SHA-256 written into the script. On a mismatch it stops and changes nothing.
  4. Adds one pinned APT source at /etc/apt/sources.list.d/signfield.sources. The pin lets it supply signfield only, never replace another package.
  5. Installs SignField and stops. No background service. Future versions arrive with your normal apt upgrade.
